# Orbit Taco

A fictional taquería concept by Thirty3 Digital Designs, exploring the intersection of lively street-food culture and retro space-diner personality.

**Live:** https://orbit-taco.vercel.app

## What's included

- Responsive, photography-led home page and restaurant-inspired visual identity
- Menu filter for tacos, sides, and drinks
- Interactive demo cart with quantity controls, subtotals, salsa preference, and sample pickup window
- Demo confirmation with **no real orders, payments, saved personal information, or backend requests**
- Accessible mobile menu, keyboard-enabled cart drawer, reduced-motion support, and photo fallbacks
- Clear portfolio-project disclosure throughout

## How to edit

This project is intentionally a single `index.html` file with inline styles and JavaScript, so it can deploy as a static site on Vercel without a build step. Update the `items` array near the end of the file to edit sample menu names, prices, photos, and descriptions. All amounts are demonstration-only.

## Images and fonts

Photography is served from Pexels, which provides free-use licensing for these photographs. Selected photographers include Los Muertos Crew, Gonzalo Guzmán García, Daniela Velarde, and Cristian Arteaga. Replace demo photos with real client photography for a production restaurant site. External photo images are loaded dynamically from Pexels and require an internet connection.

Fonts are loaded from Google Fonts: Bowlby One SC, Barlow Condensed, and DM Sans. System-font fallbacks are provided.

## Important

Orbit Taco is **not a real restaurant**. The sample menu and pickup flow should never be misrepresented as a real ordering service. To convert this concept into a real business website, add a real location, verified operating hours, official menu, secure ordering backend or reputable ordering platform, proper legal/privacy notices, and real customer support contact details.
